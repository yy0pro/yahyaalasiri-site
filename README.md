# موقع yahyaalasiri.com

موقع ثابت مبني بـ Astro، يُنشر تلقائياً على Cloudflare Pages مع كل تحديث في هذا المستودع.

## كيف أكتب مقالاً؟

عبر محرر Pages CMS (رابط المحرر يُفتح من app.pagescms.org بصلاحية حسابك في GitHub).

المقالات ملفات Markdown داخل:

src/content/articles

الصور المرفوعة من المحرر تُحفظ في:

public/assets/uploads

## تشغيل الموقع محلياً

- npm install
- npm run dev
- npm run build

## ملاحظات

- خيار «مسودة» في المحرر يمنع نشر المقال دون حذفه.
- فيديو يوتيوب: ألصق رابط الفيديو في سطر مستقل وسيتحول تلقائياً إلى مشغل مدمج.

## تلوين النصوص

اكتب داخل النص:

- :teal[نص فيروزي]
- :amber[نص ذهبي]
- :red[نص أحمر]
- :muted[نص رمادي خافت]

وتُعرض ملوّنة في صفحة المقال تلقائياً.

## لوحة التحكم (كتابة المقالات)

افتح: https://yahyaalasiri.com/admin

- تُربط مرة واحدة برمز GitHub محدود (Fine-grained token) لمستودع هذا الموقع فقط.
- محرر نصوص كامل (حجم خط، ألوان، محاذاة، جداول، وسائط، صور بالسحب).
- كل حفظ = تحديث مباشر للموقع خلال دقيقة.

## وضع التطوير

من لوحة التحكم: زر واحد يضع الموقع في وضع التطوير — يرى الزوار صفحة «قيد التطوير» بدلاً من المحتوى، وتبقى اللوحة /admin متاحة للإيقاف.
